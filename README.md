# argocd-mq-usecase-2

Dedicated cluster and Argo CD application configurations for GCP Project `mq-usecase-2`.

## Structure
- `gke-managed-cluster/`: Managed cluster 1 (VPC1 subnet 1) dedicated values and config.
- `gke-managed-cluster-2/`: Managed cluster 2 (VPC1 subnet 2) dedicated values and config.
- `gke-managed-cluster-3/`: Managed cluster 3 (VPC2 subnet 1) dedicated values and config.
- `gke-managed-cluster-4/`: Managed cluster 4 (VPC2 subnet 2) dedicated values and config.
